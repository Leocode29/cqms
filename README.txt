# Client Query Management System (CQMS)

A Streamlit-based web app for managing client queries, tracking statuses, and generating support metrics.

## Features
- 🔐 User login & registration (Client / Support roles)
- 📝 Query submission (Individual + Bulk CSV upload)
- 📊 Support dashboard with query analytics
- 🕒 Auto calculation of resolution time

## Tech Stack
- Python, Streamlit, Pandas
- MySQL (via pymysql)
- Git + GitHub for version control
